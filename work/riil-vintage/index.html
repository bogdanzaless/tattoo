РИИЛ Винтаж

An AI stylist bot for vintage stores.

ConceptCreative concept, user journey and game mechanics.
AI

Context and task

Vintage stores needed a digital service that could help with a real fitting-room choice and continue after the visit.

Creative idea

Place an AI stylist in Telegram and open it with a QR code inside the fitting room.

How it worked

The bot gave styling recommendations and then moved the user into the Build a RIIL Look game, extending the same interaction beyond the store.

My role

Creative concept, user journey and game mechanics.

Project status

Concept. Not launched.
