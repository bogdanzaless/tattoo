Context and task

The concept needed to turn a standard March 8 greeting into a shared action.

Creative idea

Let branded stickers collectively upgrade one gift shown in a dynamic post.

How it worked

Every sticker moved the gift forward. Useful prizes were mixed with deliberately awkward options, giving the audience a reason to keep improving the result.
