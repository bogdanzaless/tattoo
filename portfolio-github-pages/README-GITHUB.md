# GitHub Pages deployment

1. Upload the contents of this folder to the root of your repository.
2. In GitHub open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Keep the custom domain set to **bogdanzaless.ru** and enable HTTPS after DNS verification.

The package already includes CNAME, .nojekyll, 404.html, sitemap.xml, robots.txt and all assets.
