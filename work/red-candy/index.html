MTS RED

Не тариф, а конфетка

A collectible game based on the tariff's features.

ConceptCreative concept, game mechanics, product integration and naming.
RED

Context and task

The tariff's different benefits needed one clear game system.

Creative idea

Turn every product feature into a separate virtual sweet and the full tariff into a collectible box.

How it worked

Users collected the complete set to enter a draw for physical boxes and larger prizes. Each sweet explained one function through its place in the collection.

My role

Creative concept, game mechanics, product integration and naming.

Project status

Concept. Not launched.

Visual materials and formats

  • Virtual sweet collection
  • Product-feature system
  • Prize draw mechanic
